## 3つの道具の役割（1行で）

混ざりやすいので、ここに置いておく。詳しい図は **P3-1 の責務の分担図**。

| 道具 | ひとことで | 向いている方向 |
| --- | --- | --- |
| **Pydantic** | **外**とやり取りする形の設計図 | API ↔ 外の世界 |
| **SQLAlchemy** | **表**の形の設計図 + SQL を組み立てる係 | アプリ ↔ MySQL |
| **Alembic** | 表の形を**いつ・どう変えたか**の履歴 | 過去 ↔ 現在の表 |

> **Pydantic と SQLAlchemy はどちらも「データの形を書くもの」に見える**が、向いている方向が逆。
> ここが分からなくなったら P3-1 の図に戻る。
