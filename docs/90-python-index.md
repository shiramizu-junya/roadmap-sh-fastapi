# Python 文法 逆引き索引

主線に出てきた Python の文法を、**1トークン1行**で引けるようにしたもの。
`_prompt.md` §4.3 に従い、**M1 のステップを1つ出すたびに追記する**。

**使い方**: コードを読んでいて「これ何て読むんだ / 何をしてるんだ」となったら、ここで記号を探す。
**説明の本体はここに書かない。** 説明は各ステップの `🐍 Python解説` にあり、ここはその場所を指すだけ。
同じ説明が2箇所にあると、片方が古くなったときに気づけないため。

| `IndentationError` | インデンテーション・エラー | 字下げが足りない／揃っていない。**起動時**に落ちる | **P1-2 / 2-3a(3)** |

## 記号

| トークン | 読み方 | ひとことで言うと | 説明した場所 |
| --- | --- | --- | --- |
| `@` | アット（デコレータ） | 関数に貼る付箋。**定義直後に1回だけ**実行される | **P1-2 / 2-3** |
| `=` | イコール（代入） | 右で作ったものに左の名前を付ける。`const`/`new` は無い | **P1-2 / 2-3** |
| `->` | アロー | 戻り値の型。矢印の右が「返ってくるものの型」 | **P1-2 / 2-3** |
| `:`（行末） | コロン | 「ここからブロックが始まる」の合図。忘れると構文エラー | **P1-2 / 2-3** |
| `{...}` | なみかっこ | 辞書。鍵で値を取り出す入れ物。**鍵はクォートで囲む** | **P1-2 / 2-3** |
| 字下げ | インデント | `{}` の代わり。**見た目ではなく文法そのもの**。半角4つ | **P1-2 / 2-3** |
| `|` | パイプ（ユニオン型） | 型の「または」。TS の `\|` と**記号まで同じ** | **P1-3 / 3-3** |
| `= None`（既定値） | イコール・ノン | 省略時の値。**FastAPI では「省略可能か」の判定に直結** | **P1-3 / 3-3** |
| 末尾カンマ | — | 引数を複数行に分けたときの慣習。ruff が自動で付ける | **P1-3 / 3-3** |
| `#` | シャープ | 行末までのメモ。Python は読まない。TS の `//` | **P1-4 / 4-3** |
| `.`（機能を使う） | ドット | その物が持つ機能を使う印。`todos.append(...)` | **P1-4 / 4-3** |
| `.`（import の中） | ドット | フォルダの区切り。`app.schemas.todo` = `app/schemas/todo.py` | **P1-4 / 4-3** |

## キーワード

| トークン | 読み方 | ひとことで言うと | 説明した場所 |
| --- | --- | --- | --- |
| `from ... import ...` | フロム・インポート | 箱から道具を1つ出して使えるようにする | **P1-2 / 2-3** |
| `def` | デフ | 関数を定義する。下の字下げされた範囲が中身 | **P1-2 / 2-3** |
| `return` | リターン | 答えを返して関数を終える | **P1-2 / 2-3** |
| `class 名前(親):` | クラス | ひな形を作る。`()` の中を引き継ぐ（継承） | **P1-4 / 4-3** |
| `True` / `False` | トゥルー / フォルス | はい／いいえ。**先頭が大文字**。JSON では `true` / `false` | **P1-4 / 4-3** |

## 書き方のかたち（構文）

| トークン | 読み方 | ひとことで言うと | 説明した場所 |
| --- | --- | --- | --- |
| `dict[str, str]` | ディクト・ストリング・ストリング | 鍵も値も文字列の辞書。`[]` の中が中身の型 | **P1-2 / 2-3** |
| `Annotated[型, 情報]` | アノテイテッド | 荷物に札を2枚貼る。1枚目が型、2枚目は読みたい道具だけが読む | **P1-3 / 3-3** |
| `None` | ノン | 「値が無い」専用の値。0 でも空文字でもない。JSON では `null` | **P1-3 / 3-3** |
| クラスの中の `名前: 型` | — | 欄（フィールド）。`=` が無ければ必須、あれば省略時の値 | **P1-4 / 4-3** |
| `bool` | ブール | はい／いいえの2択だけが入る型 | **P1-4 / 4-3** |
| `list[型]` / `[]` | リスト | 順番つきの入れ物。`[]` は空。TS の `型[]` | **P1-4 / 4-3** |
| `.append(x)` | アペンド | リストの末尾に1つ足す。TS の `push` | **P1-4 / 4-3** |
