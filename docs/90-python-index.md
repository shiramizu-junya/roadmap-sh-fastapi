# Python 文法 逆引き索引

主線に出てきた Python の文法を、**1トークン1行**で引けるようにしたもの。
`_prompt.md` §4.3 に従い、**M1 のステップを1つ出すたびに追記する**。

**使い方**: コードを読んでいて「これ何て読むんだ / 何をしてるんだ」となったら、ここで記号を探す。
**説明の本体はここに書かない。** 説明は各ステップの `🐍 Python解説` にあり、ここはその場所を指すだけ。
同じ説明が2箇所にあると、片方が古くなったときに気づけないため。

## 特に丁寧に扱うもの（4点セット + 🪜 なぜなぜ つき）

`_prompt.md` §4.3 で「見た目から意味が推測できず、かつ FastAPI の理解に直結する」と指定されたもの。
出てきた時点で、他より厚く扱う。

| トークン | 読み方 | 初出の見込み | 状態 |
| --- | --- | --- | --- |
| `@` | アットマーク（デコレータ） | P1-2 | 未 |
| 型アノテーション（`x: int`） | コロン | P1-2 | 未 |
| `None` / `Optional` | ノン / オプショナル | P1-5 | 未 |
| `self` | セルフ | P1-4 | 未 |
| 内包表記（`[x for x in y]`） | リスト内包表記 | P1-7 | 未 |
| `with` | ウィズ | P3-1 | 未 |
| `yield` | イールド | P3-1 | 未 |
| `async` / `await` | エイシンク / アウェイト | P3-1 | 未 |

> 初出の見込みは、`00-plan.md` のステップ一覧から立てた**予定**。実際に出た時点で更新する。
> 予定より早く出てしまった場合は、**その場で説明する**（後回しにしない。§4.12-2）。
